BRIGHTPATH ACADEMY — 4-PAGE EDUCATIONAL WEBSITE

PAGES
1. index.html   — Home page
2. about.html   — About the project and learning approach
3. courses.html — Course cards and working category filters
4. contact.html — Contact page with front-end demo form

SEPARATE CODE / FOLDER STRUCTURE
- Each page has its own HTML file.
- assets/css/style.css contains all shared styling.
- assets/js/script.js contains navigation, course filtering, and form interactions.
- assets/ contains locally stored SVG image files.

HOW TO RUN
1. Extract the ZIP file.
2. Keep the folders and files in their original structure.
3. Open index.html in Chrome, Edge, Firefox, or another modern browser.
4. Use the top navigation to visit the other pages.

CUSTOMIZATION
- Change the name BrightPath in the HTML files to your institute/project name.
- Update course titles and descriptions in courses.html.
- Replace SVG files in assets/ with your own images if desired.
- Edit colors, spacing, and fonts in assets/css/style.css.

NOTE
This is a front-end educational demo. The contact form displays a browser confirmation only; it does not send email or store submissions. There is no login, database, or course enrollment backend.
